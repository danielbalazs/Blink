# Blink

Scan a QR code on your screen with one click. Blink lives in the macOS menu bar: click the icon and any QR code on screen opens in your default browser, in the background.

- **Click:** scan the screen (the display under the mouse first)
- **Option-click:** drag to select an area, for small or crowded codes
- **Right-click:** recent scans, trusted sites, Launch at Login, Check for Updates
- Wi-Fi codes (join or copy the password), email/phone links, contact cards and 2FA setup codes are handled safely
- Warns before opening suspicious links (short links, raw IP addresses, look-alike domains)
- Automatic updates

## Download

**[Download the latest Blink](https://github.com/danielbalazs/Blink/releases/latest/download/Blink.zip)** — macOS 14 or later, Apple Silicon and Intel.

First launch: Blink isn't notarized yet, so right-click `Blink.app` → **Open** → **Open**. Then allow **Screen & System Audio Recording** for Blink when macOS asks, and reopen it once.

This repository hosts releases and the update feed (`appcast.xml`) used by the app's built-in updater.
